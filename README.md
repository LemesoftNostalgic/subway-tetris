**How it plays**

- **The goal, not lines:** each level places an amber "PLATFORM" line a bit above the middle (its height shifts between levels: rows 6–10). You win by making every column's top land *exactly* on that line — holes below are fine, but any block poking above blocks the train. When the surface is flat, the signal flips green, the Line-7 train horns, crosses the bridge over the gap, and the whole platform cascades away for a level bonus plus a time bonus.
- **One subtle rule handled for you:** the flat surface row is technically a "full line" in Tetris terms. The game intercepts that moment — if it completes with nothing above it, it's a win, not a line clear — so the goal is actually achievable.
- **Difficulty curve:** Level 1 gives 2:30, then the clock tightens by 12s per level (floor 55s), gravity speeds up, and the target line moves.
- **Feel & juice:** 7-bag randomizer, ghost piece, DAS auto-repeat, hard-drop dust, screen shake, line-clear flashes, train sparks, confetti, per-column progress pips with an "obstruction" warning, chiptune music + full SFX (all synthesized in Web Audio, no files), pause/mute, touch controls on mobile, and a persistent station record in `localStorage`.

**Controls:** ← → move · ↑/X rotate · Z counter-rotate · ↓ soft drop · Space hard drop · P pause · M sound · Enter/R to start or reboard.
